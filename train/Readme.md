# 项目文件说明

## 任务场景说明
本项目的任务场景为**两架飞机扫描并攻击地面敌方（假设敌方静止）**的空对地攻击。  
初始状态为两架飞机均运行初始的搜索模板；当搜索到敌方飞机后，进入决策与攻击流程。

### 决策（动作模式）
飞机可选择以下动作模式（离散动作）：

- `0`：初始模式，飞机进行搜索敌方  
- `1`：保持上一个动作模式  
- `2`：飞机进行直线飞行  
- `3`：飞机左拐  
- `4`：飞机右拐  
- `5`：飞机进行攻击 — 攻击需满足：已捕获到敌方且飞机与敌方距离**不小于 10000 米**

- `X`：也可以增加其他的宏动作
飞机也有应飞控制模式（连续控制--速度、方向、高度）封装的有解算函数

### 指标及要求
- 当两架飞机中的任意一方扫描到敌方后，可以选择两架飞机中的任意一架进行攻击（需满足攻击条件）。  
- 当一架飞机进行攻击时，希望另一架飞机**持续探测**目标，以尽量避免丢失视野（即保持“探测—攻击”协同）。  
- 搜索模式仅作为**初始模式**，不参与后续决策；若两架飞机在一次扫描捕获后**长时间均丢失视野**，则两架飞机均应回到初始模式（reset）重新搜索。

#### 主要评价指标
1. 尽可能减少丢失视野的次数与时长。  
2. 提高攻击成功率。  
3. 从初次发现敌方到成功击毁敌方的时间尽可能短。

## 项目文件说明
- `README.md`：本文件，介绍项目的基本信息。  
- `requirements.txt`：项目依赖的第三方库（只包含项目相关依赖）。  
- `environment/env.py`：环境配置示例。  
- `environment/jiaoben.py`：脚本程序，将源 `.pyd` 文件替换到本目录下并转化为 `.pyi` 格式。  
- `environment/AirCombat_demo.pyd`：由 C++ 生成的供 Python 调用的动态链接库文件。  
- `environment/AirCombat_demo.pyi`：`.pyi` 类型定义文件（对应 `.pyd`）。  
- `demo.py`：示例脚本，演示如何调用 `AirCombat_demo.pyd` 中的函数。
